# API de libros con FastAPI y Supabase

Esta API permite listar, buscar, agregar, actualizar y eliminar libros. FastAPI recibe las
solicitudes HTTP y Supabase guarda los datos de forma persistente en una tabla
PostgreSQL llamada `libros_tp`.

## Archivos principales

| Archivo | Para qué sirve |
|---|---|
| `main.py` | Define las rutas de la API y protege las operaciones de escritura. |
| `models.py` | Define el campo `titulo` y valida los datos recibidos. |
| `db.py` | Conecta con Supabase y ejecuta consultas a la tabla `libros_tp`. |
| `requirements.txt` | Lista las librerías necesarias. |
| `.env` | Guarda las claves locales; no se debe subir al repositorio. |

## Preparar Supabase

La tabla `libros_tp` debe tener una columna `id_libro` como identificador y la
columna `titulo`, que es el campo que esta API permite crear y reemplazar:

```sql
create table public.libros_tp (
    id_libro bigint generated by default as identity primary key,
    titulo text not null
);
```

Si ya tienes la tabla creada con más columnas obligatorias, tendrás que ampliar
`LibroNuevo` en `models.py` para que POST y PUT también reciban esos campos.

En la configuración del proyecto de Supabase, copia la URL del proyecto y una
clave secreta para uso de servidor. Colócala en un archivo `.env` en la carpeta
del proyecto:

```dotenv
API_KEY=pega_aqui_una_clave_larga_para_proteger_el_POST
SUPABASE_URL=https://tu-proyecto.supabase.co
SUPABASE_KEY=pega_aqui_la_clave_secreta_de_servidor
```

`SUPABASE_KEY` debe ser una clave secreta de servidor (`sb_secret_...` o la
clave heredada `service_role`), no una clave para usar en el navegador. No
compartas ni subas `.env`: esa clave permite que el servidor acceda a la base de
datos. El `.gitignore` del proyecto ya excluye ese archivo.

## Instalar y ejecutar en Windows

Desde PowerShell, en la carpeta del proyecto:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload
```

Abre `http://127.0.0.1:8000/docs` para probar la API.

## Endpoints

| Método | Ruta | Descripción | Protección |
|---|---|---|---|
| GET | `/` | Confirma que la API está activa. | No |
| GET | `/libros` | Lista libros; acepta `?titulo=texto` para filtrar. | No |
| POST | `/libros` | Inserta un libro. | Header `X-API-Key` |
| PUT | `/libros/{item_id}` | Reemplaza el título del libro indicado (404 si no existe). | Header `X-API-Key` |
| DELETE | `/libros/{item_id}` | Elimina un libro por `id_libro` (404 si no existe). | Header `X-API-Key` |

Ejemplo del cuerpo para `POST /libros` y `PUT /libros/{item_id}`:

```json
{"titulo": "El nombre del libro"}
```

Para POST, PUT y DELETE, envía el header `X-API-Key` con el mismo valor
configurado en `API_KEY`. En `/docs`, usa **Authorize**; en Postman, agrega el
header manualmente.

## Cómo está conectada la aplicación

1. `main.py` recibe la petición y valida el cuerpo con `LibroNuevo`.
2. `main.py` llama a una función de `db.py` para ejecutar la operación sobre el libro.
3. `db.py` usa `supabase.table("libros_tp")` para consultar o modificar filas.
4. Supabase devuelve los resultados y FastAPI los responde como JSON.

La base de datos administra `id_libro`, por eso el cliente no debe enviarlo al
crear un libro.

## Cambiar el objeto del proyecto

Si la tabla `libros_tp` tiene más campos editables, agrégalos al modelo
`LibroNuevo` y asegúrate de que las columnas coincidan en Supabase.
